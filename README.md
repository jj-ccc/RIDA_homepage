# RIDA project page

Project page for [RIDA](https://github.com/jj-ccc/RIDA): A Universal Rank-Invariant Domain Adaptation Method for
Biomedical Image Segmentation. Served with GitHub Pages at <https://jj-ccc.github.io/RIDA_homepage/>.

Static site, no build step:

```
index.html            page
static/css/style.css  styles (light and dark)
static/js/data.js     result tables of the paper
static/js/main.js     charts and interactive panels
static/img/           figures and qualitative results
```

Local preview: `python -m http.server 8000` in this folder, then open <http://localhost:8000>.
